# CIGO PDF Studio v0.5

Editor PDF sperimentale per browser, predisposto per una futura versione Windows.

## Funzioni
- Apri, ruota, riordina, elimina, unisci ed esporta pagine PDF.
- Inserisci testo, rettangoli ed evidenziazioni.
- Regola l’altezza dell’evidenziatore.
- Elimina le annotazioni con lo strumento «Cancella annotazione».
- Annulla e ripristina le modifiche (Ctrl+Z / Ctrl+Y); esporta con Ctrl+S.

## Avvio
Pubblica `index.html` su GitHub Pages oppure usa un server locale. Richiede connessione Internet per caricare PDF.js e pdf-lib dalle CDN. I documenti vengono elaborati localmente nel browser.

## Limiti
Il testo aggiunto con font Helvetica potrebbe non riprodurre correttamente alcuni caratteri Unicode; l’evidenziazione è geometrica e non seleziona automaticamente le parole. La versione Windows non è ancora inclusa.
