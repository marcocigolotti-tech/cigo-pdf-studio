# CIGO PDF Studio v0.7

Editor PDF sperimentale per browser, predisposto per una futura versione Windows.

## Novità v0.7
- Modalità **Evidenzia testo selezionato**: seleziona con il mouse le parole di un PDF testuale. La selezione crea annotazioni evidenziate, incluse nell'esportazione.
- Resta disponibile **Evidenzia area** per i PDF scannerizzati e le zone senza testo selezionabile.

## Utilizzo
Apri `index.html` tramite un server web o pubblicalo su GitHub Pages. Le librerie PDF.js e pdf-lib sono caricate tramite CDN: è necessaria una connessione Internet per il caricamento iniziale.

**Limiti:** selezione testuale sperimentale, soprattutto su PDF con colonne, testi ruotati o impaginazioni complesse; nessun OCR. L'esportazione delle annotazioni su pagine ruotate richiede ulteriore collaudo.

Ideato dal Prof. Marco Cigolotti – CIGO STUDIO, con supporto IA.
