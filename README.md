# CIGO PDF Studio v0.9

Editor PDF sperimentale con correzione del testo a impaginazione fissa.

## Novità
La precedente modalità Word, che ricostruiva e spostava tutto il documento, è stata disattivata. Scegli **Correggi testo nella pagina** e clicca su un frammento di testo per sostituirlo senza spostare griglie, immagini o altri elementi. Il programma rifiuta le sostituzioni più lunghe dello spazio originale.

## Limiti tecnici
La correzione usa una copertura bianca e sovrascrive visivamente il frammento; **non elimina il testo originale dal contenuto PDF**, che può restare selezionabile o ricercabile. Non è una redazione sicura e non va usata per oscurare informazioni riservate. Su sfondi colorati, tabelle con bordi, font speciali e testo ruotato il risultato può essere imperfetto. Non è un editor Word completo. Usare una copia del PDF originale.
