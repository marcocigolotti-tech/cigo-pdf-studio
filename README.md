# CIGO PDF Studio

**Editor PDF per Web e Windows**

CIGO PDF Studio è un progetto per visualizzare, annotare, modificare e organizzare documenti PDF attraverso un'interfaccia semplice e intuitiva.

## Funzionalità del progetto

- Visualizzazione dei documenti PDF
- Aggiunta di testi e annotazioni
- Gestione e riordinamento delle pagine
- Unione di documenti PDF
- Esportazione dei documenti modificati

## Sviluppi futuri

- Conversione PDF in Word e altri formati
- Riconoscimento del testo (OCR)
- Modifica avanzata del testo originale
- Applicazione installabile su Windows

## Stato del progetto

Versione sperimentale 0.1, attualmente in sviluppo e perfezionamento.
